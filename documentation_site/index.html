System Documentation

Intelligent Campus Notifications.

A unified, role-based platform replacing fragmentation with clarity. Real-time alerts, digital workflows, and seamless communication for the modern institution.

Role-Based Access

Distinct secure views for Students, Faculty, and Admins.

Real-time IO

Instant delivery of critical campus updates.

Digital OD

Paperless on-duty request and approval workflow.

Targeted Channels

Topic-specific spaces like Discord for the campus.

Technology Stack

Frontend

  • Next.js 14+ (App Router)
  • TypeScript & React
  • Tailwind CSS (Dark Mode)

Backend

  • Node.js & Express
  • Socket.io (Real-time)
  • JWT Auth & Multer

Database

  • PostgreSQL
  • Firebase Config
  • Relational Schema
